Ouvre cette page sur le téléphone à installer (Android), par exemple en scannant ce code. Compte 5 minutes et une connexion Internet.

  1. Installe Termux et Termux:Widget depuis F-Droid, pas le Play Store : Termux Termux:Widget Sur chaque page, tout en bas : « Télécharger l'APK ». Android demandera d'autoriser ce navigateur à installer des applis.
  2. Ouvre Termux et colle cette commande (appui long → Coller, puis Entrée) : 
    {{COMMAND}}
    {{TOKEN_NOTE}}
  3. Réponds aux questions : le code hôte (les chiffres qui donnent la main sur ce téléphone), puis Entrée pour passer Spotify. Les playlists Deezer et les liens Spotify publics marchent sans rien.
  4. Pose le widget : appui long sur l'écran d'accueil → Widgets → Termux:Widget → « Blind Test ». Puis Paramètres → Applications → Termux → Batterie → Non restreinte.

Ensuite, à chaque soirée : touche « Blind Test », le navigateur s'ouvre sur la salle en mode hôte, la TV ouvre l'adresse « Écran TV » affichée dans Termux, les invités scannent le QR code.
